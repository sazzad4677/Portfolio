## 🚀 Key Features

### 🛠️ Cutting-Edge Architecture

- **Next.js 16 (App Router)**: Utilizing the latest Server Component architecture for lightning-fast page loads and optimized data fetching.
- **React 19 Core**: Leveraging the newest React features for enhanced performance and stability.
- **Server-Side Rendering (SSR)**: Full content visibility for search engines from the very first byte.

### 🔍 Elite SEO & Performance

- **Dynamic Sitemap & Robots**: Automated discovery and indexing foundation.
- **Semantic HTML5**: Perfected heading hierarchy (H1-H6) for maximum search relevance.
- **JSON-LD Structured Data**: Built-in Schema.xml support for rich search snippets and professional branding.

### 💎 Premium User Experience

- **Signature 0-100% Loader**: A bespoke, branded entrance animation that guards content hydration.
- **Framer Motion Orchestration**: Smooth, cinematic transitions and scroll-driven interactive elements.
- **Responsive Mastery**: Fluid design system optimized for everything from ultra-wide monitors to high-density mobile displays.
- **Dual-Theme Engine**: Premium "Navy" dark mode and light mode support with zero-flicker injection.

## 🏗️ Getting Started

### Prerequisites

- Node.js 18.x or higher
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/sazzad4677/myportfolio-sazzad.dev.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```

### Development
Run the development server with Turbopack:
```bash
npm run dev
```

### Production Build
Generate a production-ready bundle with full SSR optimization:
```bash
npm run build
```

## 📂 Project Structure

- `src/app/`: Next.js App Router (Headers, Metadata, Sitemaps).
- `src/components/`: Modular UI components (Hero, About, Works, etc.).
- `src/lib/`: Core logic, types, and centralized Content Management.
- `src/views/`: Main page orchestration and layout guards.
- `public/`: Optimized assets and professional credentials.
